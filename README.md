# 薪跳 SalaryDance

> 常驻 DSH 界面右上角的实时薪资跳动悬浮卡片。

![界面结构示意图](docs/preview.svg)

把「今天赚了多少」变成一个自己往上跳的数字。时薪按**当月实际工作日**（扣除法定节假日、计入调休上班日）算出来，所以逐月变化。

## 安装

```bash
dsh plugin --profile desktop add github:zhouxf08/dsh-plugin-salary-dance
```

装完**完全退出 DSH 再打开**（`⌘Q`，不是关窗口）—— profile 的插件组合在启动时读取。

也可以在侧边栏 **Plugins → Add plugin** 里填同一串地址。装好后侧边栏出现「薪跳 SalaryDance」、界面右上角出现卡片，就成功了。

## 使用

| 操作 | 效果 |
| --- | --- |
| 拖动卡片顶部 | 移动位置（限制在窗口内） |
| 点顶部 ▢ 图标 | 完整视图 ↔ 精简视图 |
| 点顶部 ⚙ 图标 | 打开设置面板 |
| 点步骤条 `1 / 2` | 直接跳到那一步 |
| 滚动 / 拖动 / 方向键 | 设置时间时选小时与分钟 |

设置只有两步：**薪资模式**（月薪 / 日薪 / 时薪）和**工作时间**（当月工作日历 + 上下班 + 可选午休）。深浅色跟随 DSH 的「外观」设置，没有独立开关。

想恢复默认：清掉浏览器 `localStorage` 里的 `dsh-plugin-salary-dance/config.v1`。

## 计算口径

```
D  = 本月周一至周五天数 − 其中的法定节假日 + 其中的调休上班日
H  = 班次跨度 − 与班次求交后的午休时长
时薪 = 月薪 ÷ D ÷ H            ← 所以逐月变化
今日入账 = 日薪 × 已工作时长 ÷ H
```

例：月薪 8000、10 月 `D = 18`、`H = 8` → `8000 ÷ 18 ÷ 8 = ¥55.5556/时`。

- 金额显示 **4 位小数**，每帧按当前时钟现算并**向下取整**：只会落后于真实入账，不会超前。
- **午休期间不累积薪资**，卡片显示金色「午休中」标记，结束后自动继续。
- 休息日进度为 0、入账为 `¥0.00`。
- 支持**跨夜班次**：下班时间早于上班时间即视为次日（22:00 → 06:00）。
- 内置 **2025 / 2026** 法定节假日表，逐条抄自国务院办公厅通知原文：
  [2025](https://www.gov.cn/zhengce/zhengceku/202411/content_6986383.htm) ·
  [2026](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)。
  表外年份退回「周一至周五」，也可以在设置里手填本月工作日。

## 数据

配置只存在本机浏览器的 `localStorage`，无账号、无网络请求、无运行时依赖。卡片位置不持久化。

## 限制

- 节假日表只到 **2026 年**，2027 起需要补表，否则退回周一至周五。
- 卡片可见时每帧重渲染（约 60fps）；页面切到后台会自动暂停，不消耗资源。
- 只适用于带浏览器载体的 profile（`desktop` / `web`）。在 DSH `0.2.0-rc.2` 上开发与验证。
